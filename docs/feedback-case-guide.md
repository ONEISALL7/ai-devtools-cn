# 用户反馈到公开案例：可执行指南

目标：把反馈变成对外可复核的项目资产，不把 maintainer 自测或不当内容写成外部证据。

## 适用范围

本指南适用于以下来源：

- 外部 feedback issue
- 外部 pilot feedback issue
- 公开讨论中的有效使用场景

不适用：

- 私聊内容未授权公开
- maintainer 自测占位 issue
- 缺少上下文的泛泛夸奖

## 先区分反馈来源

在整理案例前，先记录反馈来自哪里，以及是否得到公开或匿名引用授权。来源不同，能否进入公开证据台账的规则也不同：

- **外部 feedback issue**：来自非维护者账号的公开 Issue。保留 Issue 链接和作者身份时，可以作为外部反馈证据；如需改写内容，仍要避免暴露敏感信息。
- **匿名化私聊反馈**：反馈来自私聊、邮件或群聊时，只有在取得匿名引用授权后，才能整理为公开案例。不得把私聊原文、截图或内部链接直接复制到仓库。
- **维护者自建 issue 或自测**：可以作为内部改进线索，但不能标记为 external feedback，也不能计入 external PR、外部采用或公开用户数量。
- **公开讨论或 PR 评论**：如果包含明确的使用场景、问题和可核验链接，可以作为外部反馈来源；只有在能确认贡献者身份和授权边界时，才保留署名。

## 处理流程（4 步）

### 1）判定来源和可信度

- 是否来自 maintainer 账号；如果无法判断，先按“待核验”处理，不直接计入外部反馈。
- 是否有可核验链接（issue、PR、comment、release）。
- 是否明确使用场景。
- 是否包含隐私、凭证、客户信息或内部系统细节。

### 2）决定可转化类型

- **外部反馈 issue**：可直接计入 evidence ledger。
- **匿名案例**：来自私聊或不便公开时，先征得匿名引用授权，再删除可识别信息并保留授权记录。
- **反馈驱动维护**：维护者提交的新 PR/issue/案例要注明“来自外部反馈”，但不计作 external PR。

### 3）建立反馈到交付的闭环

- 为反馈创建或关联改进 Issue，写清问题、影响范围和验收标准。
- 在 PR 描述中关联来源 Issue，并说明修改内容和验证方式。
- 发布后补充 release 或 changelog 链接，形成“反馈 -> 改进 Issue -> PR -> release”的闭环。
- 写入 `work/external-evidence.md`：日期、类型、来源链接、作者或匿名标识、授权状态、可核验性和后续交付链接。
- 在公开模板案例中补齐输入、输出、验收标准。

### 4）在公开前复核边界

- 没有授权的私聊内容不公开，也不保留可反推出来源人的细节。
- 不把维护者自测、内部测试或占位 Issue 写成外部采用证据。
- 所有链接都指向公开页面，不包含私有仓库、内部域名、日志地址或访问令牌。
- 如果来源、授权或作者身份仍不明确，保留为内部改进线索，等待补充证据。

## 隐私与安全边界（强制）

- 不上传 token、客户信息、公司专有代码片段。
- 发布前匿名化项目名、服务名、账号信息。
- 不公开 internal 环境 URL、私有仓库地址。

## 可复用输出样式


## 发布前检查清单

- [ ] 已确认来源类型和作者身份，不能确认时标记为“待核验”。
- [ ] 已获得公开署名或匿名引用所需的授权。
- [ ] 已删除 token、客户名称、内部 URL、私有代码和个人隐私信息。
- [ ] 已区分 external feedback、maintainer 自测和反馈驱动维护。
- [ ] 已关联公开 Issue、PR 和 release/changelog，或明确说明尚未完成的环节。
- [ ] 已由维护者复核案例是否可复现、是否夸大能力以及是否超出原始反馈范围。

## 与 OpenAI 申请口径联动

只有以下条目可写入“公开采用证据”：

- 外部反馈 issue 数量与示例链接。
- 外部 PR 提交与合并记录。
- 公开案例（去敏后）是否可复制使用。
- 真实用户场景是否用于 PR review / issue triage / CI / release。

## 快速入口

- Feedback 草稿：
  - `npm run templates:feedback`
  - `npm run templates:outreach`
- 证据账本：
  - `npm run metrics:snapshot -- --output work/metrics-YYYY-MM-DD.md`
  - `npm run templates:evidence -- --output work/external-evidence.md`
